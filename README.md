# Akshit Joshi — Personal Portfolio

Modern responsive portfolio built with plain HTML, CSS and JavaScript. Hosted with GitHub Pages.

## Files
- `index.html` — page content and SEO metadata
- `styles.css` — layout, visual design and responsive styles
- `script.js` — navigation, project filters and case study dialogs
- `assets/Akshit_Joshi_Resume.pdf` — redacted public résumé (phone number removed)

## Run locally
Open `index.html` in your browser, or run `python -m http.server 8000` and visit http://localhost:8000.

## Deployment
GitHub → repository Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save. Live URL: https://akshitjoshi101.github.io/

Update files and commit changes to main to publish updates.
